# P1参考研究证据摘记

查询日期2026-10-18。使用web搜索/网页读取，未下载或使用参考产品的品牌封面、字体或图标。以下为摘要与推论，不是界面截图审计。

1. Apple [曲库播放](https://support.apple.com/guide/music-windows/play-songs-from-your-library-mus36265ad9/windows)：官方描述侧栏分类/歌单进入音乐、搜索及播放控制。读取正文。听屿推论：稳定分类、明确库内搜索；不引入商店/订阅。
2. Apple [Mini Player](https://support.apple.com/en-gb/guide/music-windows/mus71d7dcfce/windows)：正文提及封面、进度、歌词、接下来及全屏播放器入口。读取正文。听屿推论：持续播放入口和全屏舞台互补，不能把多层播放器堆在同一页。
3. Spotify [Your Library](https://support.spotify.com/us/article/your-library/)：正文说明桌面侧栏、移动菜单栏、搜索与筛选。听屿推论：跨屏任务一致，布局各自适应。
4. Spotify [Now Playing](https://support.spotify.com/us/article/now-playing/)：正文说明移动迷你播放区在菜单栏上方，可点击展开，另有收藏/随机/循环/队列操作。听屿推论：固定迷你条和显式队列入口；不迁移Connect或社交。
5. Plex [Plexamp官方页](https://www.plex.tv/en-gb/plexamp/)与[官方体验文章](https://www.plex.tv/blog/plex-pro-week-24-my-plexamp-music-journey/)：直接打开均403；仅搜索返回的官方索引摘要可读。文章摘要介绍从封面提取背景色。只据此探索夜航氛围，不声称核验了当下Plexamp界面、版本或收费范围。

研究限制：没有登录这些服务，没有完成产品连续操作，没有用搜索结果推断实际触控/性能表现。三套方案的具体色彩、布局、虚构内容是听屿设计探索，不是来源产品的事实或复制。
