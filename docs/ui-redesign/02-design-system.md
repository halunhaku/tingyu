日期：2026-10-18。用户先以“c”选择声档，再以“确认”批准本P2 v0.1提案（提交c5dbe18），包括下列三项细节。[批准记录及哈希](decision-c.json)冻结依据。P3只先实施全屏播放及关联控件，不把规范批准当成全部页面或实机验收通过，亦不授权自动更新Golden。

## 1. 已确定的设计语言与审批边界

保留纸白/石墨中性色、琥珀强调、克制描边和小圆角、中文无衬线与等宽数字。桌面曲库以可扫描表格为主，来源可追溯；手机以歌曲列表为主；全屏播放脱离外壳，队列区分“当前播放 / 接下来”。不加入封面书架、推荐流、霓虹背景或新音效功能。

允许按P1已记录的问题制定精确修复：正确专辑/缺封面数据、长标题不撞时长、来源筛选不挤压主按钮、去掉重复队列入口。选中图稿中的文字错误与非正方封面不当作设计合同。

以下三项已随P2提案获用户确认，实施后仍需以实际截图验收：

| 事项 | v0.1提案 | 确认前边界 |

| 手机工具区/行高 | 计数与播放第一行；排序/来源筛选第二行，歌曲最小64、双行标题最小88 | 不直接实施或用固定截图冒充已验证布局 |
| 舞台几何 | 手机封面优选240，桌面360，短窗降级与队列独立展开 | 不将生成图巨大留白当必须保留的精确位置 |

JSON单一数值来源为 [voice-archive.v0.1.json](tokens/voice-archive.v0.1.json)，[Flutter映射](tokens/flutter-mapping.v0.1.json)说明复用/替换/新增语义。重要改动需用户明确确认；小修复也必须有具体审查问题和前后证据。

所有几何使用Flutter逻辑像素，字体数值以文本缩放1.0为基准；带透明度颜色用Flutter的 `#AARRGGBB`，不是CSS八位色顺序。界面只读语义token；Material内建控件通过现有 `TyTheme.colorScheme` 继承，禁止在页面写另一套ColorScheme。

`surfaceHover`为正文色约4%/浅色字约6%叠加，`surfacePressed`约8%/10%；`surfaceSelected`与`accentSoft`为强调色约12%/14%。叠加在当前surface上，不能把半透明色当已经合成的实色。选中、hover、pressed不反复叠成三层：优先pressed→selected→hover→默认。

焦点环使用focusRing（与accent同值），2px外环+2px间隔；不能被父级裁切。禁用态不响应hover，tooltip或邻近文字说明原因。紧急错误不是禁用态。正文、状态文字在实际合成底上验证≥4.5:1，交互图标/焦点/必要边界目标≥3:1。完整计算见 [颜色验证](p2-evidence/token-validation.json)，不将其当成实际Flutter渲染或完整无障碍验收。

## 3. 字体、图标、间距与形状

复用 `TyType` 的13个现有样式，不引入字体依赖。默认中文/英文保持同一无衬线界面，数字使用 `FontFeature.tabularFigures()`；不把中文、艺术家或整行文本设成等宽。

| token | 字号 / 字重 / 行高倍数 | 角色 |
|---|---|---|
| displayL / displayM | 40/700/1.20；32/700/1.25 | 桌面舞台曲名/长标题降档 |
| titleXL / titleL | 26/600/1.30；20/600/1.35 | 页面标题/手机舞台曲名/对话框 |
| titleM | 17/600/1.40 | 分组、来源名称 |
| bodyL / bodyM / bodyS | 16/400/1.60；15/400/1.50；13/400/1.50 | 艺术家说明/曲名正文/元数据 |
| labelL / labelM / labelS | 15/500/1.40；13/500/1.40；11/600/1.30 | 按钮/导航/短徽标 |
| numericM / numericS | 15/500/1.40；13/500/1.40，等宽数字 | 时间/计数 |

字距默认0，只有短徽标labelS为0.3；关键来源状态/错误信息不得降为11px。文本缩放不关闭、不夹到1.0，不因英文长标题缩到小字号。标题桌面最多两行；手机曲名最多两行后省略，保留完整Semantics及详情入口，不能只依赖hover tooltip。

字体沿用macOS/iOS苹方回退、Windows Segoe/微软雅黑、Android/Linux Noto系统回退。系统字体变化可能影响换行，不能声称跨平台像素一致。Windows当前字体哈希见 [环境记录](p2-evidence/font-environment.json)，只是本机证据，不包含授权再分发字体。未来Golden固定同一镜像和实际加载的字体集；仅固定两个文件不足以证明引擎使用了这些字体，运行前还需核实加载链。

间距阶梯保持2/4/6/8/12/16/20/24/32/40/48/64；2与6仅作图标/细节微调。页面左右留白compact20、medium24、expanded32；数据列表间距8/12，独立分组间距24/32。不为对齐生成图临时增加散点常量。

圆角基础阶梯复用TyRadius（4/8/10/14/20/full），**组件不统一用同一个大圆角**：按钮/输入/表格选中/小封面4，舞台封面/来源卡片8，对话框10，抽屉顶部14；主播放键为圆。所有专辑封面严格1:1，以BoxFit.cover裁切，禁止拉伸。头像可圆形，缺封面占位无随机图案/随机颜色。

图标复用现有Material Icons，不新增图标包：内联14、行内16/20、工具栏24、次级播放28、主播放圆56。轮廓图标用于常态，填充/明确标记用于选中或收藏；同一语义不混用多套图标。图标尺寸不等于命中区。

列表与普通面板无装饰阴影，深色靠层次与描边。Light菜单阴影黑10%、blur16、offset(0,4)；模态sheet黑14%、blur32、offset(0,12)；保留现有palette阴影语义供命令面板使用，不扩散到曲目行。

## 4. 响应式与密度

沿用 `FormFactor`：compact<640、medium 640–1023、expanded≥1024，均依据实际逻辑宽度，不依据操作系统。触控、hover、右键、快捷键仍由 `PlatformTraits` 决定；窄Windows窗不能作为手机手势验收。

| 项目 | Compact | Medium | Expanded |
|---|---|---|---|
| 导航 | 4个底部Tab | 88宽rail | 248侧栏，可折叠72 |
| 内容左右留白 | 20 | 24 | 32 |
| 浏览播放条 | 64最小迷你条，位于64导航上方 | 72传输条 | 88传输条 |
| 歌曲行最小高 | 64；双行标题88 | 52 | 48 |
| 表格行最小高 | 使用列表 | 48 | 44，紧凑40 |
| 通用命中区 | ≥44 | 鼠标≥40；触控≥44 | 鼠标≥36；触控≥44 |
| 主播放控制命中区 | ≥48 | ≥48 | ≥48 |
| 全屏播放 | 单栏+独立歌词/队列 | 单栏+独立面板 | 左控制区+380右面板 |

高度是textScale=1时的**最小值**，不是ClipRect高度。文字放大后由内容撑开；compact忽略紧凑密度。所有底栏高度另加相应SafeArea inset且只加一次。键盘出现时不以固定底部堆叠遮挡输入，搜索结果区可滚动。

### 表格按内容区收拢

内容可用宽度W已扣侧栏/rail、左右留白及滚动条。列序：leading40、封面40、曲名min240（吃剩余宽度）、艺术家136、专辑144、来源88、时长56、更多36；列间距12。leading在序号/播放图标之间切换，不额外插入一列。

| W | 列策略 |
|---|---|
| ≥864 | 全列 |
| 708–863 | 收起专辑列 |
| 560–707 | 再收起艺术家列，在曲名副行显示艺术家 |
| 460–559 | 再收起来源列，通过行菜单/详情查看来源 |
| <460或compact外壳 | 单列歌曲布局，无行号；曲名/艺术家/必要时长优先 |

公式864=40+40+240+136+144+88+56+36+7×12；删除一列同时删除一个gap。不能把1024当成“必能放八列”；例如1440窗口、248侧栏和64留白后W=1128放全列，而1024窗口W=712只放收拢列。滚动条减去后仍按实际W决策。

手机工具区第一行“12首歌曲 / 播放全部”，第二行“标题排序 / 全部来源”；屏更窄/文字放大时第二行只留“筛选与排序”入口，打开复用的面板。正文不加重复来源徽标串，默认副标题只放艺术家；筛选结果或来源详情才显示必要来源上下文。隐藏一列不删除功能、来源状态或可访问名称。

## 5. 组件合同

| 组件/现有落点 | v0.1规范 |
|---|---|
| 主/次/图标按钮 `buttons.dart` | 同屏只有一项主要任务用实心琥珀；次要动作描边/文字；busy不重复提交；有tooltip与Semantics |
| 搜索/输入 `inputs.dart` | 完整占位“搜索曲库”；Ctrl/Cmd F只是次级提示；清除可见可读；沿用现有debounce，不改查询/分页语义 |
| `TyTrackRow / TyTrackTable / TyTrackList` | 共用曲名/收藏/当前态；桌面选择和双击/右键遵循既有语义；不新增未经支持的批量引擎操作；手机长按不替代可见更多入口 |
| `TyMiniPlayer / TyTransportBar` | 只出现一套浏览播放控件；封面/曲名进入舞台；播放/暂停/下一首常显。来源/封面未知也保留可识别标题 |
| `TyPlayerStage` | 覆盖整个外壳；关闭恢复原浏览上下文，不能重置队列或进度；收藏与播放状态复用provider |
| `QueuePanel` | 当前播放单独分组，接下来不重复当前曲；时长固定56列，标题最多两行；不能因为重构改变随机队列映射 |
| `LyricsPanel` | 不伪造歌词或时间轴；缺歌词说明+队列入口；自动跟随/手动滚动行为按既有能力验证，不新增逐字歌词引擎 |
| `TySourceCard` | 类型/名称→状态与曲数→详情；同步/重试是同一主操作槽的不同态；更多菜单承载删除/配置，不把危险动作做主按钮 |
| `TyAsyncView / TyEmptyState / TyErrorView` | 覆盖loading/error/empty/data，错误需原因与可执行恢复；禁止裸白屏/静默吞错 |
| 对话框/抽屉/命令面板 | 桌面宽度按内容限宽，手机宽度随SafeArea；焦点进入、关闭返回触发点；Esc/返回均保留既有路由语义 |

舞台默认展示C的队列意图，但尊重已有 `?tab=lyrics|queue` 显式请求与用户上下文，不覆盖它。播放器源于media_kit/just_audio的状态直接复用；展示需要从provider派生，不得另写一套“看起来在播放”的本地布尔状态。

### 播放舞台精确规则提案

桌面左内容列最大420，封面优选360、上限420；右面板380，左右间距48，左右外边距各32，顶部关闭区48。封面随高度收敛到120，歌词/队列自身滚动，不把主控挤出屏幕。

手机优选240正方封面，顺序：关闭/更多→封面→曲名/艺术家/专辑→进度→五键传输→唯一歌词/队列tab→当前tab内容。高度<720时队列预览不常驻，保留44高明确入口，展开独立面板；不是删除队列功能。大字/横屏优先主控、曲名与进度可达，封面区允许滚动并降到120，不让固定区覆盖正文。出现系统键盘、底部手势区时按实际安全高度处理。

进度轨道视觉4，命中高度44；拖动过程只本地预览，松手只调用一次既有seek；未知duration禁用拖动并以“--:--”表达，不伪造0秒总长。音量只调用现有setVolume，移动平台如交由系统音量则不绘制无效滑杆，不新增AirPlay/设备切换入口。

## 6. 加载、空态、错误与中间态

| 场景 | 展示与恢复 |
|---|---|
| 首次加载曲库 | 保留标题/导航/播放条；固定行骨架，预留封面空间；禁止spinner占满屏幕 |
| 分页加载 | 已有内容保留，页尾局部进度；失败页尾“加载失败 / 重试”，不误显示空曲库 |
| 整库为空 | “还没有音乐”+“添加来源”；这是显式导航动作，不自动扫描或导入 |
| 搜索无输入/无结果 | 前者提示搜索范围；后者保留关键词/筛选，提供清除或修改，不诱导添加来源 |
| 没有当前曲 | 舞台给返回曲库入口；浏览迷你条隐藏；不留无意义的空播放条 |
| buffering/resolving | 主控显示明确忙碌状态，曲名/队列保留；不把playing=true当已经有声音 |
| 播放失败 | 浏览条和舞台共享同一failure派生状态，保留曲名与原因；明确重试/队列/返回。不能只在底条错误、舞台仍显示“正常播放” |
| 来源未连接/过期 | 用现有status错误分类与原因；“重新登录/配置”导航；不能自动刷新凭据或静默删除来源 |
| 同步中/取消/部分成功 | 复用SourceSync状态与计数；有进度则显示真实进度，无总量时用不定进度；取消后不伪称同步完成 |
| 缺封面/封面失败 | 固定占位，保留布局和曲名；不使用随机封面，不反复网络重试 |
| 无歌词/歌词加载失败 | 区分“不存在”和“请求失败”；真实错误才给重试，不编造歌词 |

重试必须明确调用已有失败任务/控制器能力；若现有togglePlayPause不能保证重试失败项，单独登记业务缺陷，不在UI层模拟重试成功。Toast用于非阻断反馈；持续错误留在对应区域，可由读屏得知，避免每个播放tick重复播报。

## 7. 动效、键盘与无障碍

复用TyDuration：micro90、fast120、base200、sheet240、stage320、cover180ms；shimmer1400ms。常规曲线(0.2,0,0,1)，进/出沿用TyCurve。声档不主动新增背景漂移；保留已有封面取色偏好，不迁移默认值、不重写用户设置。`disableAnimations`时共享元素/缩放/漂移/骨架微光停用，使用直接切换；播放进度保持功能但不触发无关重建。

键盘规则：沿用现有Space播放/暂停、Ctrl/Cmd F搜索、Esc关闭层级；快捷键作用于正确焦点范围，文本输入时Space不能拦截为播放。未在当前代码核实的快捷键必须另登记实现，不能在UI标签先宣传。Tab顺序与视觉顺序一致，不以颜色标记焦点，不造成焦点陷阱；模态关闭返回触发控件。

语义规则：图标按钮均有状态化名称（播放/暂停、收藏/取消收藏）；滑杆有当前/总时长与增减动作；来源状态既有图标又有文字；选中与正在播放使用不同语义。曲库行不能把内部按钮全部合并为一个不可访问节点；完整曲名包含在可访问名称里。

无障碍目标参考W3C [文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[最小目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[可见焦点](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)（本轮已查阅，2026-10-18）。44逻辑像素是本项目触控设计下限，不把它误写成WCAG 2.2 AA的24 CSS像素条款；原生Flutter实际可用性仍须设备验证。文字200%测试不隐藏关键播放/返回/来源入口。不以颜色验证、截图或静态Semantics检查宣布整体合规。
